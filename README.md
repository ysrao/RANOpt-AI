# RANOpt AI

## AI-Assisted 5G/6G RAN Optimization Platform

RANOpt AI is an interactive AI-assisted platform for evaluating, optimizing, and demonstrating 5G and future 6G Radio Access Networks (RAN).

The platform combines:
- Rule-based AI
- Reinforcement Learning (PPO)
- Natural Language Voice/Text Interaction
- Carrier-grade KPI analysis
- Interactive system-level simulation

## Key Features

- 5G/6G RAN system-level simulator
- FDD and FDD+TDD deployment modes
- Multi-layer spectrum planning
- Carrier Aggregation (up to 4 CCs)
- AI-assisted optimization
- PPO Reinforcement Learning
- Natural language voice/text interface
- Automated NLP validation
- Professional KPI dashboard
- Interactive "what-if" network optimization
